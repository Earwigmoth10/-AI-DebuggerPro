Frequently Asked
Questions

  • AI Debugging is the use of automated, model- or rule-based analysis to scan your code and flag bugs, vulnerabilities, and bad practices — without you having to manually trace through every line.

  • AI Debugger Pro combines a trained ML model with deterministic rule-based checks, so you get both a confidence-scored risk category and the exact line number of the issue in one report.

  • It's built for developers, students, and small teams who want fast feedback on code quality and security without setting up a full static-analysis pipeline.

  • The core analysis runs behind a simple REST API (Flask), so it can be called from CI scripts, editor plugins, or any tool that can make an HTTP request.

  • Coverage includes missing semicolons and unclosed tags, SQL injection and XSS risks, deprecated functions, and general bad practices across JavaScript, PHP, Python, HTML, and SQL.

  • Since it runs in the browser and over a REST API, AI Debugger Pro works alongside any local setup, editor, or OS — there's nothing environment-specific to install.

  • It fits naturally into code review and pre-deploy checks: catch issues during development, save reports for later review, and track history over the life of a project.

  • Code you submit is analyzed to produce a report and is not shared with third parties. When self-hosted, you control the server, the database, and how long reports are retained.

  • The rule-based checks are transparent and inspectable in rules.py, and the ML model's accuracy is reported openly — nothing about the scoring is a black box.

  • There's no built-in limit — it's a tool you run against as many codebases and projects as you like, whether hosted locally or deployed for a team.
